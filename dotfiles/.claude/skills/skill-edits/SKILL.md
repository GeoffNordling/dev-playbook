# Skill Edits

Skills and rules under `~/.claude/` are **symlinked from dev-playbook**. Always edit the source files, not the symlink targets.

- **Mac (Darwin):** `/Volumes/workplace/dev-playbook/dotfiles/.claude/`
- **WSL:** `~/workspace/dev-playbook/dotfiles/.claude/`

After any edit, commit and push from the **dev-playbook** repo — not from whatever project you are working in.
