# Write the Rules

## Confirm each home

The home came from the index. The index gives one line for each standard,
so it can put a rule in the wrong place.

For each rule the user accepted, {Read the standard its home names}, all
of it. Confirm four things:

- Its population holds the files the rule reads.
- The section's concern is the rule's concern.
- No rule in it already says the same thing. Where one does, the missing
  piece is its verifier, not a new rule. Say so and write nothing.
- No rule in it contradicts the new rule.

Where the home fails, find the right one the same way and tell the user
before you write. Where no home is right but a new standard, stop and ask.
