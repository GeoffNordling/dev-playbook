# Present-State Documentation

Write documentation that focuses on the current state and future next steps, in a way that provides minimal but sufficient information for an agent to act from the current state moving forward. Do not reference past historical information unless it is an important historical condition needed for an agent to understand the current state and take appropriate steps going forward.
