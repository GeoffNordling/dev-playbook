# Explanation Residual Ledger

Explanation's residual record: what
[Reasons](/doc-types/explanation/contract-shape.md) cannot express.
That is all an entry is — a record.

## Explanations

Per Explanation written to the encoding: what the Reasons could not
express, recognized and written down at the moment of writing. Entries
name subjects, Reasons, and trailers in the vocabulary
[encoding.md](/doc-types/explanation/encoding.md) declares.

An entry is a couple of sentences, hard limit: name each specific thing
the file could not express and why the shape cannot say it, nothing
else. An Explanation with nothing to record has no entry. No
Explanation is written to the encoding yet, so the ledger holds none.
