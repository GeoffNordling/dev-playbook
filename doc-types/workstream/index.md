# doc-types/workstream/ — index

The Workstream doc-type: one line of work, driven by a loop — its
definition, contract shape, encoding, and residual ledger. The rules a
head file obeys are
[Workstream Conventions](/standards/doc-type/workstream-conventions.md).

- [Headings and Stints](/doc-types/workstream/contract-shape.md) — Workstream's contract shape — a head file of peer headings picked from one menu, a ledger of stints, and a parent and children derived from the directory — in prose and as code
- [Headings and Stints Encoding](/doc-types/workstream/encoding.md) — The layer below the shape — how a Workstream's head file writes its frontmatter, its headings, and its stints so a check can read them, and where the file sits
- [Workstream](/doc-types/workstream/definition.md) — What a workstream is — one line of work, its ideas, target state, and context — driven by a loop and adding no verb, the family it serves, and where it lives
- [Workstream Heading Menu](/doc-types/workstream/heading-menu.md) — The headings a Workstream's head file picks its H2s from, each with what it holds
- [Workstream Residual Ledger](/doc-types/workstream/residual-ledger.md) — Workstream's residual record — what headings and stints cannot express, one entry per Workstream that has one
