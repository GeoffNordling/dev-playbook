# harness-recipes/ — index

Multi-agent orchestration patterns worth reusing, each a prose recipe backed
by the code and skills that run it. Start at
[Harness recipes](/harness-recipes/README.md).

- [Harness recipes](/harness-recipes/README.md) — Reusable harness orchestration patterns — prose descriptions of multi-agent workflows backed by code and skills
- [Judgments](/harness-recipes/recipes/judgments.md) — Filling a repo's judgment cache in one call — plan the docket, fan out one pinned judge per miss, record the passes, return only what was refuted
- [Ralph loop](/harness-recipes/recipes/ralph-loop.md) — Grinding a large task to done by booting a fresh agent each iteration, with plan and progress carried on disk
- [Scatter-gather](/harness-recipes/recipes/scatter-gather.md) — Running a batch of independent jobs in one parallel fan-out — one fresh agent per job, results in input order
