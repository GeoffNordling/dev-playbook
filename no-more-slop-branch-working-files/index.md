# no-more-slop-branch-working-files — Bundle Index

Temporary tracking files for the `no-more-slop` branch. The whole folder is
deleted when the branch merges; material drains out of it into long-term
locations as it settles. The files below already carry their future
basenames; [migration.md](/no-more-slop-branch-working-files/migration.md)
holds their future locations.

Start at [No More Slop](/no-more-slop-branch-working-files/NO-MORE-SLOP.md):
it is the branch plan, and it holds the goal, the terms, and the next steps
for the work as a whole. The other files hang beneath it.

One subdirectory carries no index of its own, and
[runbook-encoding.md](/no-more-slop-branch-working-files/runbook-encoding.md)
owns what it holds: `parser/`, holding `chaingen.py` and `chains.txt`.

- [Doc-Type System](/no-more-slop-branch-working-files/doc-type-system.md) — This repo's doc-type instantiation — the registry rulings, the roster of built doc-types, and the import surface for consumer repos
- [Migration](/no-more-slop-branch-working-files/migration.md) — The move plan that takes the working files to their long-term homes — the path table, the standards/ split, and the wiring that lands with it
- [No More Slop](/no-more-slop-branch-working-files/NO-MORE-SLOP.md) — The branch plan — goal, the two tracks, the terms, and the current step
- [Reference Chain](/no-more-slop-branch-working-files/runbook-contract-shape.md) — The Reference chain — Runbook's contract shape, declared as nodes and edges
- [Reference Chain Encoding](/no-more-slop-branch-working-files/runbook-encoding.md) — The layer below the contract shape — the spec a writer follows to encode chain edges in runbook prose
