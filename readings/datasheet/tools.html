Purpose

A grab-bag of workspace developer tooling: the pre-commit hooks that guard every repo's Python, markdown, and knowledge-bundle conventions; the deterministic half of the LLM-judgment system; and the exporter that turns a Claude Code session into an XML transcript. They share a checkout and a test suite but no runtime path — each is invoked on its own. It exists so the workspace's conventions and audit trails are enforced by code, not vigilance.

Shape

inputinternaloutput

Three disconnected tracks — the lint hooks (through the shared lib helpers), the judgments pipeline, and transcript-export — with no hub joining them; ref-check, internal-skill-audit, bootstrap-labels, and griffe-outline are four more standalone tools not drawn.

Tool roster

Pre-commit hooks: python-lint (no-future-annotations, empty-init, test-privacy), okf-lint (document-type frontmatter + index-staleness), ref-check (root-absolute links and workspace citations), judgments-lint (declaration field/path validation), internal-skill-audit (SKILL.md conventions). Judgments: judgments-run (plan/render/record) over the loader, core (content key + judge prompt), and the skipcache seen-set; the pytest cache-gate stands on the same pieces. transcript_export: client (agentsview boundary) → model (normalize + resume-dedup) → forks (live path + abandoned branches) → render (XML), orchestrated by transcript.render_session recursing into sub-agents. Standalone: bootstrap-labels (GitHub label scheme via gh), griffe-outline (package structure report via griffe). lib: md and pyast — the markdown/AST primitives the hooks share.

Assessment opinion

  1. A bag of tools, not a systemthe Shape is three disconnected tracks plus four more standalone tools; a change to one implies nothing about the others (Shape).
  2. The judgment gate trusts one machine's cachegreen means a key sits in a local seen-set that only a human-run LLM judge fills, and CI skips the gate entirely (Seen-set, Tests).
  3. Transcript fidelity rides on one daemon versionthe whole suite fakes agentsview at v0.34.5; a single local-only canary is all that would notice the daemon drifting (Rewind fork, Tests).
  4. A content key can reuse a stale verdictthe cache identity hashes only the declared claim, files, model, and effort — anything influencing the judgment from outside that set changes it without changing the key (Content key).
  5. Label sync deletes to match a closed worldthe one tool that mutates outside the repo removes every GitHub label not in its canonical set (Touch surface).
