Purpose

The workspace's local enforcement layer: six independent checkers that hold every repo to the shared standards — build layout, OKF docs, cross-references, Python conventions, skill conventions, and GitHub settings — before code lands. Five run as pre-commit hooks at commit time; sweep runs on demand across the whole workspace. Three shared library modules give them one gitignore-aware, worktree-scoped view of a repo's files, so discovery is defined once rather than re-implemented per tool.

Data flow

inputinternaloutput

Three disconnected tracks: four file-linters share one git ls-files backbone; internal-skill-audit walks skill bundles on its own; sweep reads the whole workspace over the network. The disconnection is the point — this is three kinds of tool, not one pipeline.

Shared modules

The git ls-files node is three sibling modules the linters import: md (markdown fences, slugs, links, frontmatter, OKF classify, find_md_files); pyast (Python discovery and AST parse, find_python_files); gitrepo (canonical repo name and git_files). Each answers the same question — which files does this checkout contain? — once.

Assessment opinion

  1. The sixth checker ships unverifiedinternal-skill-audit is the one tool with no test suite, so a regression in its skill-conformance rules would pass silently (Tests).
  2. The audit trusts the artifacts shipped beside itrepo-audit and sweep judge every repo against the canonical files in their own clone, so a wrong canonical makes real repos "conform" to the wrong shape (Canonical artifact).
  3. Findings are text, not a schemaeach tool prints location · rule · message; anything scripting against that parses stdout, and a format change breaks it with no warning (Finding).
  4. Coverage is exactly what git seesdiscovery lists tracked and untracked files, so a gitignored file is never scanned and an untracked one always is (Worktree-scoped discovery).
  5. The shared backbone is tested only through its callersgitrepo and pyast have no direct suite, so an edge case in the git or AST helpers surfaces only if a tool's own test happens to hit it (Tests).
