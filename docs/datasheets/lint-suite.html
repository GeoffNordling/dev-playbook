Purpose

The enforcement arm of the workspace standards: six pre-commit hooks that catch drift — repo structure, Python conventions, markdown health, skill conformance, workspace hygiene — in any consumer checkout. It exists so a standard is a gate, not a document: a repo violating the build or docs standards cannot commit. Consumers pin a rev of this hook repo, and the canonical artifacts travel inside the clone.

Command grammar above — five linters share tool [<dir>]; sweep has its own track. Exit 0 clean · 1 findings · 2 cannot run, uniform across all six. Importable surface below: the shared primitives (md, pyast, gitrepo) every linter builds on.

Data flow

inputinternaloutput

Six independent tracks — each hook is its own pipeline from one slice of the checkout to its findings stream; only repo-audit and sweep take a second input (canonical artifacts; GitHub settings).

Module roster

md.py — fence-aware markdown reading: frontmatter, links, heading slugs, the OKF path taxonomy. pyast.py — Python file discovery and AST parsing. gitrepo.py — repo naming and gitignore-honoring file listing. Each executable script is standalone; the six hooks share only these three modules.

Assessment opinion

  1. A clean audit is only as strong as layer inferencerepo-audit checks the rules of the layers it infers from disk facts, so a layer that fails to infer is silently not audited (layer).
  2. One parser bug moves three tools at onceokf-lint, ref-check, and repo-audit's doc checks all read files through the same primitives, so a fencing edge case shifts them together (fence-aware parsing).
  3. The skill auditor ships unverifiedinternal-skill-audit has no dedicated suite; a regression there surfaces only in real commits (Tests).
  4. Output formats split by toolfive tools emit text finding lines while ref-check emits JSON records — a consumer scripting one shape breaks on the other (finding line, API).
  5. Workspace hygiene is visible only when GitHub issweep's settings rows arrive over gh api, so offline or unauthenticated runs can't see settings drift (Touch surface).
