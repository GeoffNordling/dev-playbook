Purpose

Blocks a commit before a documentation or Python-source convention silently drifts: four independent gates each walk one lens over the repo — OKF frontmatter and index freshness, Python source hygiene, cross-reference integrity, and this repo's own SKILL.md conformance — and print one line per violation. They share only two small discovery helpers and the same finding-line output shape (Gate contract), because pre-commit is the last cheap moment to catch a broken link or a stray convention before it ships.

Shape

inputinternaloutput

Four independent tracks converge only at the finding-line output: okf-lint alone routes the shared markdown list through classify before checking it; internal-skill-audit scans its own skill directories directly, sharing no discovery code with the other three.

Module roster

okf-lint — OKF frontmatter type-lint + index-staleness. python-lint — no-future-annotations, empty-init, test-privacy. ref-check — Link/Citation resolution and fragment-anchor checks. internal-skill-audit — SKILL.md front-matter and body-shape conformance. lib/md.py — markdown primitives (fences, slugs, frontmatter, classify, discovery) shared by okf-lint and ref-check. lib/pyast.py — Python-file discovery and AST parsing, used by python-lint.

Assessment opinion

  1. internal-skill-audit breaks the suite's own output contractit has no test file in this scope, and — alone among the four — its exit code never separates "warnings only" from "clean" (Tests, Gate contract).
  2. classify is a single point of failure for okf-linta path it mis-buckets (concept vs. index vs. harness) silently mis-scopes both the type-lint and the index-staleness check in the same pass (classify).
  3. Three of the four gates only see what git already knowsokf-lint, ref-check, and python-lint discover files through git ls-files, so an untracked or freshly-renamed file is invisible until it's added; internal-skill-audit alone scans the filesystem directly (Worktree-scoped discovery).
  4. lib/pyast.py has no test file of its ownits two functions are exercised only indirectly, through python-lint's tests — a discovery regression there could hide behind unrelated rule failures (Tests).
  5. A clean exit only covers the rules that existall four gates report zero findings on this repo today (Behavior); that says nothing about a convention nobody has encoded as a rule yet.
