# README Content

A README's floor is its OKF frontmatter — `type: README`, `title`,
`description`, per [document-types.md](/standards/docs/document-types.md) —
followed by an H1 and a one-line purpose. This is the floor, not the
ceiling: depth varies by project ("Scope is standardized; depth is not" —
[bundle.md](/standards/docs/bundle.md#principles)), and a README `MAY` add
prerequisites, quick-start, architecture overview, or examples as the
project earns them. It `SHALL NOT` contain agent instructions or
architecture decisions — those live in `CLAUDE.md` and `docs/decisions/`.
