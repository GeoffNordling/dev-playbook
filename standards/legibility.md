# System Legibility

Governs how a human understands a large system they did not write and
will not read directly.

## Define

- [The Datasheet](/instruments/datasheet.md) — the fixed-section, budgeted
  report giving a system's owner trust and direction without reading its
  code
- [The File Graph](/instruments/file-graph.md) — the total, typed map of a
  repository's files and the references connecting them

## Audit

- none — nothing checks that a system has a current legible view

## Enforce

- none

## Adopt

- none
