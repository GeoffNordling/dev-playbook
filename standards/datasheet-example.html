Concepts

Key the column set that defines row identity
First-wins of identical-key rows, the earliest survives
Seen keys the pass's memory; grows with each unique row

Purpose

Removes duplicate rows from CSV files so downstream reports never double-count. Exists because exported data arrives with repeated records and no upstream fix is available.

Behavior verified: run exhibit: captured

$ cat contacts.csv
name,email
Ada,ada@x.io
Ada,ada@x.io
Bo,bo@x.io
$ csv-dedupe --key email contacts.csv
name,email
Ada,ada@x.io
Bo,bo@x.io

Rows sharing a key keep only their first occurrence (first-wins).

Shape

One command-line entry point (csv-dedupe) streams the input through the pure first-wins pass; only the edges touch files.

Module roster

cli.py — argument parsing and file I/O. dedupe.py — the pure first-wins pass.

Assessment opinion

  1. All file handling lives on the untested pathan argument or I/O regression ships unseen (Tests).
  2. Input order silently decides which duplicate survivesa reordered export changes output with no warning (First-wins).
  3. Seen-key memory grows without bounda very large input grows it with every unique row (Seen keys).
