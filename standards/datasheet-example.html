Purpose

Removes duplicate rows from CSV files so downstream reports never double-count. Exists because exported data arrives with repeated records and no upstream fix is available.

Behavior

verified: run exhibit: captured

$ cat contacts.csv
name,email
Ada,ada@x.io
Ada,ada@x.io
Bo,bo@x.io
$ csv-dedupe --key email contacts.csv
name,email
Ada,ada@x.io
Bo,bo@x.io

Rows sharing a key keep only their first occurrence (first-wins).

Concepts

  • Key — the column set that defines row identity.
  • First-wins — of identical-key rows, the earliest survives.

Shape

One command-line entry point (csv-dedupe) drives a three-step flow: parse arguments, stream rows through the first-wins pass, write the result. The pass is a pure function; only the edges touch files.

Module roster

cli.py — argument parsing and file I/O. dedupe.py — the pure first-wins pass.

Touch surface

Reads the input CSV named on the command line; writes the deduplicated CSV to stdout. No network, no environment variables, no subprocesses, no third-party dependencies.

Tests

The pure pass is covered against hand-built rows: key selection, first-wins order, and the empty-file case. The command-line path is untested.

Assessment opinion

  1. The untested command-line path (Tests) is where all file handling lives — an argument or I/O regression ships unseen.
  2. First-wins ordering (Concepts) lets input order silently decide which duplicate survives — a reordered export changes output with no warning.
