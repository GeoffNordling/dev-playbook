# standards/tracking/ — index

The tracking standard's contract, one concern per document: where work is
recorded, how issues are authored, how the tracker holding them is driven, and
the GitHub settings they all assume.

- [Candidate Conventions](/standards/tracking/candidates.md) — The CANDIDATES.md register of uncommitted future work — entry shape, grouping and nesting, and promotion to an issue
- [Issue Authoring](/standards/tracking/issue-authoring.md) — How a GitHub issue is authored — epic and leaf roles, readiness, the three brief formats, vertical slices, and native relationships
- [Repository Settings](/standards/tracking/repo-settings.md) — GitHub repository settings every repo should have — squash-only merges, PR message format, auto-deleted merged branches, a default branch protected from destructive operations
- [Tracker Operations](/standards/tracking/tracker-operations.md) — How the GitHub tracker is driven — the `gh` CLI surface, native sub-issues and dependencies, and wayfinding operations
