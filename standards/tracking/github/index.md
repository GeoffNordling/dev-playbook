# standards/tracking/github/ — index

GitHub Tracking, work tracked on GitHub — the Candidate register, the
issue shapes, and the label scheme. It is one of
the two ways to track work in
[Tracking](/standards/tracking/index.md).

Ordering: alphabetical by title.

- [Candidates](/standards/tracking/github/candidates.md) — The register of a repo's uncommitted future work — one CANDIDATES.md at the root, the entry shape, and the headings and nesting
- [Issue Shapes](/standards/tracking/github/issue-shapes.md) — The five species of GitHub issue and the shape of each — its labels and its body headings — the build leaf, the spike, the session leaf, the epic, and the wayfinder map or ticket, plus the rules every body obeys
- [Label Scheme](/standards/tracking/github/label-scheme.md) — The closed-world label set a governed repo's tracker mints — every label with its description, generated from the scheme data
