# standards/harness/ — index

Harness Files governs how the files Claude Code loads are written — a
CLAUDE.md's content and a runbook's format. Start at
[Runbook Conventions](/standards/harness/runbook-conventions.md). The reasoning behind the rules is
[Harness Explanation](/standards/harness/explanation.md).
