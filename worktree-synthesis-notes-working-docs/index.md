# worktree-synthesis-notes-working-docs/ — index

The working documentation set for the synthesis of the doc-type system,
Loop, the fact base, and the viewer: one root that holds what crosses
strands, the terms every strand uses, and one directory per strand.
Start at the root.

Ordering: the root, then the four strands in
plan-dependency order.

- [Synthesis Working Root](/worktree-synthesis-notes-working-docs/ROOT.md) — The root of the unified working set — four strands and their plan dependencies, the terms every strand uses, the open cross-strand questions, and the run order
- [doc-type-system/](/worktree-synthesis-notes-working-docs/doc-type-system/index.md) — The doc-type system strand, the language — the reference model, the specification, how predicates are written, ontology solvers, and the user's own words
- [loop/](/worktree-synthesis-notes-working-docs/loop/index.md) — The Loop strand, the driver — the third doc-type as a peer of Runbook and Standard, and how a loop is told what to do
- [fact-base/](/worktree-synthesis-notes-working-docs/fact-base/index.md) — The fact base strand, the compiled object — the theory, the first simulation by hand, and deterministic separation as a planned view
- [viewer/](/worktree-synthesis-notes-working-docs/viewer/index.md) — The viewer strand, a selection on screen — cloa-viewer's on-disk contract, registry of kinds, panel design, page, server, and stack
