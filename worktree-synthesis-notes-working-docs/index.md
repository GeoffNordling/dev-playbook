# worktree-synthesis-notes-working-docs/ — index

The working documentation set for the synthesis of the doc-type system,
Loop, the fact base, and the viewer: one root that holds what crosses
strands, the glossary every strand uses, and one directory per strand.
Start at the root.

Ordering: the root, the glossary, then the four strands in
plan-dependency order.

- [Synthesis Working Root](/worktree-synthesis-notes-working-docs/ROOT.md) — The root of the unified working set — four strands, doc-type system, Loop, fact base, and viewer, the plan-dependency edges between them, the cross-strand decisions and open questions, and the order the strands run in
- [Glossary](/worktree-synthesis-notes-working-docs/glossary.md) — The conceptual model of the doc-type system as a glossary — one meaning per word, from state and predicate through spec, model, verifier, finding, distribution, and loop, so every other member uses the same words
- [doc-type-system/](/worktree-synthesis-notes-working-docs/doc-type-system/index.md) — The doc-type system strand, the language — the reference model, the specification, how predicates are written, the three peers, ontology solvers, and the user's own words
- [loop/](/worktree-synthesis-notes-working-docs/loop/index.md) — The Loop strand, the driver — the third doc-type as a peer of Runbook and Standard, and how a loop is told what to do
- [fact-base/](/worktree-synthesis-notes-working-docs/fact-base/index.md) — The fact base strand, the compiled object — the theory, the first simulation by hand, and deterministic separation as a planned view
- [viewer/](/worktree-synthesis-notes-working-docs/viewer/index.md) — The viewer strand, a selection on screen — cloa-viewer's on-disk contract, registry of kinds, panel design, page, server, and stack
